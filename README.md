# UniDev Roadmaps

پلتفرم تعاملی نقشه‌راه‌های UniDev با Next.js 14، App Router، TypeScript و Tailwind CSS 3، مطابق فایل ارسالی.

نسخهٔ Next.js موجود در متن از `14.2.5` به `14.2.35` ارتقا یافته است تا اصلاحیهٔ معرفی‌شده در [اطلاعیهٔ رسمی Next.js](https://nextjs.org/blog/security-update-2025-12-11) اعمال شود.

## امکانات

- چهار نقشه‌راه: بک‌اند Django، علم داده و هوش مصنوعی، لینوکس و Docker، و فرانت‌اند ماژولار.
- صفحهٔ عمومی کشف رودمپ‌ها با ترکیب سرمه‌ای، زمردی، بنفش و فیروزه‌ای؛ حالت روشن و تاریک و ذخیرهٔ انتخاب ظاهر.
- لوگوی رسمی UniDev در سربرگ، پایین صفحه و آیکون مرورگر؛ فایل اصلی در `public/brand/unidev.jpg` نگهداری می‌شود.
- صفحهٔ «دربارهٔ یونی‌دو» در `/about` با هدف شکل‌گیری کامیونیتی، اشتراک دانش، پروژه‌های متن‌باز و آمادگی برای بازار کار؛ قابل دسترسی از منوی دسکتاپ و موبایل.
- دعوت به پرسیدن سؤال با لینک مستقیم تاپیک Questions تلگرام، لینک پیوستن به کامیونیتی و ارتباط با مؤسس.
- نقشهٔ درختی با اتصال واقعی مرحله‌ها و مباحث، کارت‌های شیشه‌ای، عمق سه‌بعدی و واکنش به حرکت ماوس.
- نمای تخت جایگزین، نمایش شاخه‌ها در موبایل و پشتیبانی از کاهش حرکت.
- آدرس عمومی مستقل برای هر رودمپ، عنوان اختصاصی صفحه و کپی لینک اشتراک.
- جستجو در عنوان مراحل، مباحث و منابع و نمایش حالت بدون نتیجه.
- حالت کارآموزی، نمایش نکات مصاحبه و ایستگاه‌های ورود به بازار کار.
- پنل منابع فارسی و انگلیسی، آموزش‌های تعاملی، مستندات و مینی‌پروژه‌ها.
- پروژه‌های پیشنهادی رزومه و فونت وزیرمتن.
- رابط فارسی و راست‌به‌چپ با پشتیبانی از موبایل و کنترل پنل منابع با صفحه‌کلید.
- نمایش تدریجی محتوا در تب‌های مباحث، منابع و تمرین؛ پشتیبانی از Escape، جابه‌جایی تب‌ها با کلیدهای جهت و کاهش حرکت.

ثبت تیک، درصد پیشرفت و امکانات شخصی فعلاً حذف شده‌اند. پنل هر مرحله فقط مباحث، منابع و تمرین‌ها را نمایش می‌دهد.

## اجرا

به Node.js نسخهٔ 20.9 یا بالاتر و npm نیاز دارید. برای دریافت فونت از Google Fonts هنگام build دسترسی به اینترنت لازم است.

```bash
npm install
npm run dev
```

صفحهٔ اصلی: http://localhost:3000

## بررسی و ساخت

```bash
npm run typecheck
npm run lint
npm run build
npm start
```

تمام داده‌های فایل ارسالی در `src/data/roadmaps.ts`، رابط عمومی در `src/components/public-roadmaps.tsx` و درخت در `src/components/roadmap-tree.tsx` قرار دارند.
برای افزودن مسیر جدید، یک عضو مطابق نوع `RoadmapData` به آرایهٔ `ROADMAPS` اضافه کنید.

متن هدف کامیونیتی و لینک‌های ارتباطی در `src/data/community.ts` متمرکز هستند. لینک گروه `https://t.me/unidev_community`، تاپیک Questions با شناسهٔ `117` و آیدی مؤسس `@Graph_ql` بر اساس اطلاعات مالک تنظیم شده‌اند. برای تغییر آن‌ها همین فایل را ویرایش کنید.

پنل مطالعهٔ هر مرحله در `src/components/step-panel.tsx` پیاده شده است. انتخاب ظاهر با کلید `unidev_theme` ذخیره می‌شود؛ داده‌های پیشرفت قبلی مرورگر در این نسخه خوانده یا تغییر داده نمی‌شوند.

برای جلوگیری از تداخل اجرای هم‌زمان، خروجی توسعه در `.next-dev` و خروجی build در `.next` قرار می‌گیرد.

آدرس‌های عمومی رودمپ‌ها:

- `/roadmaps/django-backend`
- `/roadmaps/data-science`
- `/roadmaps/linux-devops-core`
- `/roadmaps/frontend`

این مسیرها هنگام build از پیش ساخته می‌شوند و بدون ورود یا حساب کاربری باز هستند. انتشار روی اینترنت همچنان به استقرار پروژه روی یک میزبان نیاز دارد.

Tailwind CSS 3 برای سازگاری با فایل `tailwind.config.ts` استفاده شده است.


## مسیر فرانت‌اند و بازبینی محتوا

محتوای فرانت‌اند در `src/data/frontend-roadmap.ts` است: پایه‌های وب و هشت ماژول، ۵۵ مبحث، پیش‌نیازها، تفکیک هسته/تعمیق، معیار پایان، تمرین‌های اصلی و راهنمای انتخاب نقطهٔ شروع. این مسیر ماژولار است؛ اتصال‌های درخت ترتیب نمایشی را پیشنهاد می‌کنند و پیش‌نیازهای واقعی در پنل هر ماژول آمده‌اند.

سه فایل اصلی، بدون تغییر محتوای باینری، در `public/roadmaps/frontend/` نگهداری و از بخش «راهنما و فایل‌های مسیر» قابل دریافت‌اند. سه رفرنس الهام‌بخش متن اصلی جدا از ۲۲ منبع رسمی تکمیلی هر بخش نمایش داده می‌شوند.

برای بررسی ساختار داده و تطابق محتوای ماژول‌ها با فایل Markdown:

```bash
node scripts/verify-roadmaps.mjs
```

گزارش ایرادهای منابع، مقایسهٔ عمق چهار مسیر و پیشنهاد قالب مشترک در [بازبینی رودمپ‌ها](docs/roadmap-review-fa.md) نوشته شده است. نتایج HTTP منابع قبلی در `docs/resource-link-audit.json` و منابع تکمیلی فرانت‌اند در `docs/frontend-resource-link-audit.json` قرار دارند. دسترسی موفق به صفحه به معنی تأیید کامل سرفصل‌ها نیست و خطای شبکه نیز حذف منبع را ثابت نمی‌کند. محتوای آموزشی سه مسیر قبلی در این تغییر حفظ شده است.
